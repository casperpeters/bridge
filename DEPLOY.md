# Publiceren voor testers

De app is een statische website. Er is geen build-stap, server of npm-installatie nodig.

## GitHub Pages

1. Zet deze map in een GitHub-repository.
2. Ga in GitHub naar `Settings` > `Pages`.
3. Kies de branch en root-map als publicatiebron.
4. Wacht tot GitHub Pages de publieke URL toont.

Het bestand `.nojekyll` zorgt dat GitHub Pages de bestanden ongewijzigd als statische site serveert.

## Andere statische hosting

Gebruik een host die losse HTML-, CSS-, JavaScript- en assetbestanden direct kan publiceren. Publiceer de root-map van dit project, met `index.html` als startpagina.

## Voor het delen controleren

- Open de publieke URL in een browser.
- Controleer of kaarttekens zoals schoppen/harten/ruiten/klaveren goed zichtbaar zijn.
- Speel minimaal een hand uit.
- Controleer het handoverzicht na afloop.
- Test de app ook op een telefoon of tablet.
